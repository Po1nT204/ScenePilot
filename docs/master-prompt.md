Последний шаг: исправления пятиминутного пути — импорт всех сцен из Claude, безопасная проверка сохранения после сетевой ошибки, начальный план по объёму речи и выбор сохранённых сцен в качестве основы видео. Присланные пользователем 12 сцен валидны (764 слова, отличаются от сценария на 773 слова), раньше механически делились на 46 кадров при 150 слов/мин. После замечания пользователя 22 октября новый план из сцен даёт один кадр на сцену (12), сохраняя промпты и полный текст. Старые сборки не меняются. Ошибки TTS ElevenLabs теперь разбираются безопасно по известным кодам; HTTP 402 при Free/Marcus и остатке 8921 вероятно связан с ограничением Voice Library, но реальная причина пока не подтверждена. Проверки: 147 тестов, типы, lint, build прошли; реальная генерация не запускалась. Подтверждение реальной работы нового пути в Supabase ещё ожидается. Yandex: история названий, больший ответ для 2–5 минут, проверка объёма/дословности и отдельная доработка. Gemini API key ещё не получен; Claude API пока не интегрирован. Не объявлять сетевой сбой/бан доказанным по общему сообщению.

Обработчик с настоящей очередью агентом не запускался. Следующий пользовательский шаг: video:doctor → video:worker → прослушивание озвучки выбранной сборки. Не начинать Claude/Flow или большой редизайн до проверки этого пути.
