# План развития ScenePilot

Актуально на 22 октября 2026. Продукт — личный инструмент для качественных роликов на русском и английском, в перспективе до нескольких часов. Приоритет — результат видео и удобство работы, не публичный сервис.

## Текущая приёмка: путь пятиминутного ролика

Пользователь ещё не проверял подробную раскадровку и Nano Banana. Добавлены импорт сцен из внешнего чата, подтверждение сомнительного сохранения чтением, загрузка с повтором и скачивание черновика. Начальный видеоплан выбирается из сценария или сохранённых сцен. После замечания пользователя убрано обязательное дробление сцен: 12 сцен дают 12 кадров с точными исходными промптами. Прежние 46 кадров появились из механического деления речи и не являются критерием качества. Дробление по таймингам остаётся необязательным; согласованность персонажей Cloudflare не гарантирует. Добавлена диагностика отказов TTS ElevenLabs, включая HTTP 402; реальные запросы после исправления не выполнялись. Yandex получает историю названий, увеличенный ответ для 2–5 минут, проверку объёма и дословности сцен. Качество новых реальных ответов ещё не проверено; причины нестабильности Supabase/AI Studio не установлены. Claude API обсуждается, адаптер не подключён; доступен импорт из сайта.

Текущий приоритет пользователя: довести пятиминутный ролик и упростить интерфейс. 22 октября добавлены безопасная диагностика запуска worker, понятные причины остановки, короткие экраны загрузки/ошибки и уведомления Sonner на экране видео. Диагностика настоящей папки успешно прочитала 8 сборок без обработки очереди. После приёмки — пройти путь озвучка → изображения → MP4 на выбранной сборке; затем выбрать следующий шаг по выявленным препятствиям. Пять последовательных этапов создания видео реализованы. По следующему запросу пользователя обновлена главная: краткое описание пути до MP4, основной вход в «Мои ролики», иллюстрация монтажной ленты, пять этапов и профили каналов. Стили лендинга изолированы от редакторов. Текущая приёмка — внешний вид главной на широком и узком экране и переходы в рабочее пространство. После приёмки выбрать следующий шаг: дальнейшее упрощение рабочих экранов или сокращение ручного переноса Flow. Fish Audio и исследование автоматизации Flow идут отдельно; сейчас они не подключаются.

## Согласованный порядок

1. **Исправления и качество — реализованы, предварительная пользовательская проверка получена.** Дальнейшие изменения по конкретным недостаткам результата; не наращивать промпты ради объёма.
2. **Документация — завершена.** Короткий README, единый текущий план, актуальные ограничения и проверки; история отделена. Для сообщения из нового лога отключён HMR-кэш fetch в режиме разработки. Реальная задержка ещё требует проверки после перезапуска.
3. **Flow и интерфейс производства — предварительно приняты пользователем.** Пользователь выбрал сохранить подписку Flow: удобный перенос клипов сейчас, исследование управления браузером после приёмки. Экран «Видео» теперь разделён на пять последовательных этапов: сценарий, озвучка, кадры, анимация, сборка. Старые сборки сохранены; подключения свёрнуты. У кадра — выбор камеры для шаблона промпта, ссылка Flow и загрузка результата прямо в эту сцену. Публичный интерфейс генерации за кредиты Flow в проверенной документации не найден; официальный Veo API оплачивается отдельно и не подключается без нового решения пользователя. Это ручная генерация на сайте, не автоматизация.
4. **Тайминги и автоподгонка — предварительно приняты.** Показ длительности речи по кадрам; новый импорт автоматически обрезается, слегка замедляется либо повторяется со сглаженным стыком. Прежние клипы переводятся в этот режим одной кнопкой, озвучка сохраняется. Пользователь сообщил, что работает.
5. **Подробная раскадровка и Nano Banana API — текущая приёмка.** Добавлен расчёт 6/8/10/15 секунд и отдельная сборка до 120 кадров с копией готового голоса. Nano Banana API выбирается отдельно; подготовлен без реальных платных запросов. После приёмки — главы, отдельная озвучка и восстановление частей, пилот 8–12 минут с замерами. Расширять лимиты вместе с проверкой сохранности, расхода и ресурсов.
6. **Сокращение ручного переноса Flow.** Пакетная подготовка/импорт и исследование управления браузером остаются в плане. Не обещать устойчивую генерацию в один клик до проверки входа, загрузки, ожидания и скачивания. Расход кредитов согласуется отдельно.

## Отложено

- JSON-промпты как пользовательская функция и расширение универсальных сменных модулей. Существующие адаптеры сохраняются.
- Масштабный редизайн остальных страниц, смена БД/стека, копирование/удаление профилей, ИИ-помощник профиля.
- Автосохранение черновиков, история сцен, Shorts из длинного видео, Windows-упаковка, публичное размещение и автопубликация YouTube.

Бюджет пользователя для сервисов — ориентировочно $25–35 в месяц. Это ориентир выбора, не разрешение на списания. Расходы производства согласуются отдельно от разработки; платные запросы не повторяются автоматически.
