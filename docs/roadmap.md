Актуально на 29 октября 2026. Продукт — личный инструмент для качественных роликов на русском и английском, в перспективе до нескольких часов. Приоритет — результат видео и удобство работы, не публичный сервис.

## Текущий шаг: один MP4 из частей

29 октября пользователь предварительно принял подготовку частей и разрешил следующий шаг. На этапе «Сборка» добавлены список частей, выбор сборки для каждого номера, готовность, постановка полного выпуска в локальную очередь и просмотр/скачивание отдельного итогового MP4. Проверяются принадлежность одной версии, совпадение плана, актуальность и порядок частей. Старые материалы и сценарий сохраняются. Повторное нажатие не дублирует тот же выпуск; изменение выбранной части отмечает старый результат. Генерация кадров/речи не повторяется.

Приёмка: перезапустить приложение и worker → открыть версию с готовыми MP4 всех частей → «Сборка → Объединить части». Проверить выбор, нажать «Собрать весь ролик», просмотреть начало/стыки/конец, скачать и обновить страницу. Монтаж не расходует кредиты моделей. Если готовы не все части, кнопка блокируется с причиной. При отсутствии готовых частей достаточно сначала проверить список/подсказки; создание новых материалов требует прежнего отдельного подтверждения. После приёмки приоритет — полный пилот 8–12 минут, оценка звука/стыков/согласованности кадров и исправление выявленных препятствий. ИИ-предложение общих деталей и пакетное копирование промптов остаются необязательными улучшениями. Новые модели, ключи и миграции не нужны. [Инструкция](setup.md#один-mp4-из-готовых-частей).

## Текущая приёмка: путь пятиминутного ролика

Подробная раскадровка пока не принята. Nano Banana на сайте Flow пользователь оценил положительно 28 октября; официальный Google API остаётся неподключённым. Добавлены импорт сцен из внешнего чата, подтверждение сомнительного сохранения чтением, загрузка с повтором и скачивание черновика. Начальный видеоплан выбирается из сценария или сохранённых сцен. После замечания пользователя убрано обязательное дробление сцен: 12 сцен дают 12 кадров с точными исходными промптами. Прежние 46 кадров появились из механического деления речи и не являются критерием качества. Дробление по таймингам остаётся необязательным; согласованность персонажей Cloudflare не гарантирует. Добавлена диагностика отказов TTS ElevenLabs, включая HTTP 402; реальные запросы после исправления не выполнялись. Yandex получает историю названий, увеличенный ответ для 2–5 минут, проверку объёма и дословности сцен. Качество новых реальных ответов ещё не проверено; причины нестабильности Supabase/AI Studio не установлены. Claude API обсуждается, адаптер не подключён; доступен импорт из сайта.

Текущий приоритет пользователя: довести пятиминутный ролик и упростить интерфейс. 22 октября добавлены безопасная диагностика запуска worker, понятные причины остановки, короткие экраны загрузки/ошибки и уведомления Sonner на экране видео. Диагностика настоящей папки успешно прочитала 8 сборок без обработки очереди. После приёмки — пройти путь озвучка → изображения → MP4 на выбранной сборке; затем выбрать следующий шаг по выявленным препятствиям. Пять последовательных этапов создания видео реализованы. По следующему запросу пользователя обновлена главная: краткое описание пути до MP4, основной вход в «Мои ролики», иллюстрация монтажной ленты, пять этапов и профили каналов. Стили лендинга изолированы от редакторов. 23 октября по запросу пользователя выполнен общий шаг UI/UX: единая шапка и активная навигация, компактные карточки библиотеки, профили с боковым списком, формы с раскрываемой помощью, разделение основных и дополнительных действий редакторов, переходы от сценария/сцен к видео и ясное название экспорта текстов. Обновлены также оформление входа и видеостудии. По запросу пользователя следующий шаг — сокращение ручного переноса Flow — реализован 24 октября; текущая приёмка описана ниже. Перед подготовкой дополнительных адаптеров отдельно проверить официальные API и реальные бесплатные квоты Fish Audio, Google Flow и Artflow. Эти сервисы не объявляются бесплатными API и не подключены на этом шаге.

## Согласованный порядок

Техническое препятствие 23 октября устранено: Next.js и его ESLint-конфиг обновлены до 16.4.2. Проверки обновления описаны в testing.md; аудит рабочего окружения на дату той проверки не выявил уязвимостей рабочих зависимостей. Пакетный перенос Flow от 24 октября предварительно принят пользователем. Текущая приёмка — качество кадров и импорт изображений, описанные выше. Миграции и новые ключи не требуются.

1. **Исправления и качество — реализованы, предварительная пользовательская проверка получена.** Дальнейшие изменения по конкретным недостаткам результата; не наращивать промпты ради объёма.
2. **Документация — завершена.** Короткий README, единый текущий план, актуальные ограничения и проверки; история отделена. Для сообщения из нового лога отключён HMR-кэш fetch в режиме разработки. Реальная задержка ещё требует проверки после перезапуска.
3. **Flow и интерфейс производства — предварительно приняты пользователем.** Пользователь выбрал сохранить подписку Flow: удобный перенос клипов сейчас, исследование управления браузером после приёмки. Экран «Видео» теперь разделён на пять последовательных этапов: сценарий, озвучка, кадры, анимация, сборка. Старые сборки сохранены; подключения свёрнуты. У кадра — выбор камеры для шаблона промпта, ссылка Flow и загрузка результата прямо в эту сцену. Публичный интерфейс генерации за кредиты Flow в проверенной документации не найден; официальный Veo API оплачивается отдельно и не подключается без нового решения пользователя. Это ручная генерация на сайте, не автоматизация.
4. **Тайминги и автоподгонка — предварительно приняты.** Показ длительности речи по кадрам; новый импорт автоматически обрезается, слегка замедляется либо повторяется со сглаженным стыком. Прежние клипы переводятся в этот режим одной кнопкой, озвучка сохраняется. Пользователь сообщил, что работает.
5. **Подробная раскадровка и Nano Banana API — текущая приёмка.** Добавлен расчёт 6/8/10/15 секунд и отдельная сборка до 120 кадров с копией готового голоса. Nano Banana API выбирается отдельно; подготовлен без реальных платных запросов. После приёмки — главы, отдельная озвучка и восстановление частей, пилот 8–12 минут с замерами. Расширять лимиты вместе с проверкой сохранности, расхода и ресурсов.
6. **Сокращение ручного переноса Flow — реализовано, предварительно принято.** Все готовые изображения и промпты движения скачиваются одним ZIP. Несколько MP4 можно выбрать вместе, просмотреть и назначить кадрам; имена из пакета дают подсказку, порядок файлов не используется. Загрузка последовательная, после ошибки останавливается, сохранённые файлы остаются. ZIP из самого Flow пока нужно распаковать вручную. Исследование Flow Agent/Tools и браузера остаётся следующим возможным шагом после приоритета качества изображений. Генерация в один клик ещё не реализована; расход кредитов согласуется отдельно.

## Отложено

- JSON-промпты как пользовательская функция и расширение универсальных сменных модулей. Существующие адаптеры сохраняются.
- Смена БД/стека, копирование/удаление профилей, ИИ-помощник профиля. Общий UI/UX рабочих страниц уже обновлён; дальнейшие изменения — по результату приёмки.
- Автосохранение черновиков, история сцен, Shorts из длинного видео, Windows-упаковка, публичное размещение и автопубликация YouTube.

Бюджет пользователя для сервисов — ориентировочно $25–35 в месяц. Это ориентир выбора, не разрешение на списания. Расходы производства согласуются отдельно от разработки; платные запросы не повторяются автоматически.
