# Настройка окружения

Быстрые переходы: [Supabase](#supabase), [миграции](#миграции), [несколько профилей](#несколько-профилей-каналов), [производство](#локальное-производство-видео), [ElevenLabs](#elevenlabs-первое-подключение), [Cloudflare](#cloudflare-бесплатные-изображения), [Flow](#veo-через-уже-оплаченную-google-pro), [сеть](#сеть-и-режим-разработки).

Приложение запускается локально, Auth и PostgreSQL работают в Supabase. Локальная база данных не требуется. Секреты вводятся пользователем в .env.local; этот файл исключён из Git. Не присылайте его в чат и не перезаписывайте при повторной настройке.

## Supabase

1. Создать или выбрать проект в [панели Supabase](https://supabase.com/dashboard). Для учебной установки использовался план Free; платные опции не включать автоматически.
2. В Connect скопировать Project URL и Publishable key (sb_publishable_). Код принимает этот тип ключа. Secret/service_role и пароль БД приложению не нужны.
3. Один раз скопировать .env.example в .env.local, только если .env.local ещё не существует. Заполнить NEXT_PUBLIC_SUPABASE_URL и NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY по шаблону.
4. В Authentication → URL Configuration указать Site URL http://127.0.0.1:3000/login. В работе использовать 127.0.0.1, не чередовать с localhost.
5. Включить email/password. Для закрытой демонстрации можно вручную отключить Confirm email. Если подтверждение включено, после регистрации подтвердить письмо и затем войти. Настройки почты и восстановление доступа перед публичным запуском требуют отдельной работы.
6. После изменения окружения перезапустить npm run dev. Проверить вход, обновление страницы и выход по [чеклисту](testing.md).

Публичный publishable-ключ не заменяет защиту данных: её обеспечивают Auth, серверные проверки и RLS.

## Несколько профилей каналов

Если приложение уже настроено и предыдущие 12 миграций выполнены, нужен **только** [202610190001_multiple_channel_profiles.sql](../supabase/migrations/202610190001_multiple_channel_profiles.sql).

1. В Supabase → SQL Editor открыть новый запрос и вставить **весь актуальный файл**. Если предыдущий запрос оставил транзакцию в ошибке, сначала отдельно выполнить `ROLLBACK;`. Нажать Run. Ожидаемый результат: `Multiple channel profiles migration complete`. Исправленную версию именно этого файла можно повторить при ошибке `42701: column id already exists`; остальные миграции повторять нельзя. При новой ошибке сохранить её полный текст, таблицы не удалять.
2. Перезапустить приложение (`npm run dev`; для production сначала `npm run build`, затем `npm start`). Новых ключей и подписок не нужно.
3. Открыть «Профили каналов»: прежний профиль должен остаться. Через «+ Новый профиль» добавить другой, например на другом языке.
4. Нажать «Создать ролик с этим профилем» или выбрать профиль на странице нового ролика. Проверить язык, жанр и стиль, заполнить остальные поля и создать ролик вручную. Вариант «Без профиля» тоже доступен.
5. Изменить профиль и открыть созданный ролик: его требования должны остаться прежними. Подробная бесплатная проверка — в начале [testing.md](testing.md).

Повторный запуск сохраняет существующий первичный ключ id и внешние связи. Если найден неожиданный тип столбца или ключ, транзакция откатывается с диагностикой. Само наличие id не доказывает, что остальная схема установлена.

Миграция добавляет ID профилям и снимает ограничение «один профиль на аккаунт». Прежние профили, ролики и версии не удаляются, снимки не переписываются. Ссылки на профили у старых проектов остаются пустыми: их сохранённые требования продолжают работать. Облачная миграция агентом не выполнялась.

## Темп и кадры

Пользователь согласовал реализацию. Агент подготовил миграции 11 и 12, но не применял их в облаке. Выполнить только недостающие файлы целиком и по порядку: сначала темп, затем кадры. Первая добавляет новый RPC сохранения темпа только в будущих версиях. Вторая добавляет таблицы кадров/планов с RLS и сохранение стабильных ID сцен. Старые данные не переписываются и не превращаются автоматически в кадры. До обновления схемы новая запись и экспорт показывают инструкцию; платная генерация сценария проверяет готовность схемы до запроса.

После миграций выполнить [scene_shots_rls.sql](../supabase/tests/scene_shots_rls.sql) с двумя тестовыми аккаунтами, затем старые tests/scenes_rls.sql и tests/script_versions_rls.sql. Тесты заканчиваются ROLLBACK; это отдельная облачная проверка, не результат локальных тестов. Конкретный ручной путь — [testing.md](testing.md).

Длинный сценарий требует YANDEX_MODEL=yandexgpt-5.1. Для цели 301–900 секунд приложение делает один запрос с maxTokens=6000, тайм-аутом 90 секунд, прежним пределом 20 000 символов и без повторов. Короткий запрос — 2000/45. Длинные сцены остаются заблокированы. Реальная проверка требует отдельного согласования запроса и остатка бюджета. Обоснование и официальные источники — [решение](generation-and-shots-design.md).

## YandexGPT и генерация

Тестовые шаблоны работают без ключа Yandex, но требуют входа и настроенной базы.

1. В Yandex Cloud проверить облако, каталог, биллинг, квоты и доступность используемой модели. Фактическое состояние кабинета проверяет пользователь.
2. Использовать отдельный сервисный аккаунт с минимальной ролью ai.languageModels.user на каталог. API-ключ создаётся с областью yc.ai.languageModels.execute и ограниченным сроком. Нужен секрет ключа, не его идентификатор; не использовать NEXT_PUBLIC_ для него.
3. Добавить в существующий .env.local YANDEX_API_KEY, YANDEX_FOLDER_ID, YANDEX_MODEL=yandexgpt-5.1. Код также допускает yandexgpt-5-lite. Сохранять YANDEX_GENERATION_ENABLED=false до решения выполнить реальный запрос.
4. После проверки условий пользователь может установить YANDEX_GENERATION_ENABLED=true и перезапустить сервер. Сам запуск не вызывает модель.
5. Один согласованный проверочный запрос выполняется отдельной кнопкой с подтверждением. Проверить ответ, сохранить версию без повторной генерации и сверить биллинг. Тайм-аут не означает, что запрос не оплачен.

Инструкции провайдера: [API-ключи](https://yandex.cloud/ru/docs/iam/operations/authentication/manage-api-keys), [модели](https://aistudio.yandex.ru/en/docs/ai-studio/concepts/generation/models), [тарифы](https://yandex.cloud/ru/docs/ai-studio/pricing). Перед новым подключением условия нужно перепроверить.

Применимость к аккаунту и итоговая детализация пока не подтверждены; фактический расход неизвестен. После периода условия перепроверяются. Это не разрешение агенту запускать запросы автоматически.

## Локальное производство видео

Новые облачные миграции не нужны. Существующие Supabase Auth, проекты и версии сценария должны работать. До покупки проверить доступность выбранного API: наличие подписки на сайт не гарантирует API-доступ. BFL необязателен; для изображений добавлен Cloudflare SDXL. Тарифы и источники расчёта — в [плане](video-production-plan.md).

1. Сохранить короткую версию сценария, открыть «Видео» и нажать «Подготовить кадры». Это бесплатно и не требует ключей генераторов. Voice ID можно изменить до создания сборки; первоначальное значение берётся из ELEVENLABS_VOICE_ID или стандартного ID, доступность конкретного голоса в аккаунте ещё не проверена.
2. Для обработки задач в отдельном терминале из корня выполнить `npm run video:worker`. Нужны уже установленные FFmpeg и ffprobe. Если они вне PATH, задать абсолютные FFMPEG_PATH и FFPROBE_PATH. Начать можно с VIDEO_GENERATION_ENABLED=false; обработчик не отправляет новые платные запросы при выключенном флаге.
3. Подключить ElevenLabs по шагам ниже. Вначале можно проверить API при VIDEO_GENERATION_ENABLED=false, без обработчика и BFL. После решения выполнить реальную озвучку установить VIDEO_GENERATION_ENABLED=true; перезапустить приложение и обработчик.
4. В «Видео» задать предел оценки, отметить разрешение и нажать «Создать только озвучку». Прослушать или скачать MP3. Если озвучка уже готова, повторять этот шаг не нужно. Выбрать модуль изображений по инструкции ниже, проверить подключение и создать один кадр. После оценки картинки нажать «Создать оставшиеся изображения»: сохранённые озвучка и кадр повторно не создаются. Сохранение описаний бесплатно. После тайм-аута сначала сверить состояние и биллинг. «Проверить задачи изображений» читает сохранённые задачи исходного сервиса, не создаёт новый запрос генерации.
5. После материалов прослушать озвучку и нажать «Собрать MP4 на компьютере». Это повторно использует готовые файлы. Просмотреть ролик и скачать. Кнопка нового изображения относится к одному кадру и требует отдельного подтверждения.

Файлы и состояния по умолчанию находятся в %LOCALAPPDATA%/ScenePilot/production. SCENEPILOT_MEDIA_DIR может указывать на отдельную локальную папку; приложение и обработчик должны использовать одинаковый путь. Не размещать её в public или репозитории и не запускать два обработчика одновременно. При копировании проекта на другой компьютер эту папку переносить отдельно. Удаление проекта из Supabase не очищает локальные файлы; сначала скачать нужные MP4 и дождаться окончания задач. Автоматическая очистка диска пока не реализована.

Локальный технический тест рендера: `npm run video:test-render` — только синтетические временные изображения/звук, без моделей. Он не оценивает качество реального видео. Обычный `npm test` проверяет логику с подставными API и запуск обработчика с выключенной генерацией.

### Оформление существующего ролика

После обновления перезапустить приложение и обработчик. Открыть прежнюю сборку с готовыми материалами:

1. На шаге «Озвучка и сборка» снять **«Субтитры в готовом видео»**. Выбор сохраняется сразу; показанный MP4 остаётся прежним и отмечается требующим пересборки.
2. Нажать **«Собрать MP4 на компьютере»**. Новый ролик использует прежний голос и картинки, но не содержит наложенных субтитров. Генераторы не вызываются, флаг генерации для монтажа не нужен. Чтобы вернуть надписи, включить флажок и пересобрать.
3. Для изображений выбрать **«Общий стиль изображений»** над кадрами. «Как в описании кадра» сохраняет прежний запрос; остальные варианты добавляют единые инструкции. Выбор сохраняется без генерации. В «Запрос со стилем» виден будущий промпт; готовые картинки отмечаются, если описание/стиль отличаются от использованных.
4. Для оценки отдельно подтвердить **«Новое изображение»** только у одного кадра. Это запрос выбранному сервису с его квотой/стоимостью. Озвучка и остальные кадры остаются. Стиль не гарантирует реализм, одинаковых персонажей или исправления ошибок модели.

Новый план использует границы предложений; длинные предложения делятся по словам. Это бесплатное правило разбиения, не смысловая ИИ-раскадровка. Старые планы автоматически не меняются. В описании кадра полезно указать один видимый объект/действие, место, свет и композицию; пересказ абстрактной мысли сам по себе не задаёт сцену.

### Cloudflare: бесплатные изображения

Пользователь подтвердил генерацию Cloudflare SDXL без оплаты в своём тесте. Бесплатные условия и квоты нужно проверять в текущем аккаунте перед новым запуском: [страница модели](https://developers.cloudflare.com/workers-ai/models/stable-diffusion-xl-base-1.0/). Качество требует улучшений. Автоматического перехода на платную модель нет.

1. В своём аккаунте [Cloudflare](https://dash.cloudflare.com/) открыть **Workers AI → Use REST API → Create Workers AI API Token**. Нужны разрешения Workers AI Read/Edit и **Account ID**. [Официальная инструкция](https://developers.cloudflare.com/workers-ai/get-started/rest-api/).
2. В существующий `.env.local` добавить две строки, сохранив остальные настройки. Ключ не отправлять в чат:

```dotenv
CLOUDFLARE_ACCOUNT_ID=ваш_account_id
CLOUDFLARE_API_TOKEN=ваш_секретный_токен
```

3. Перезапустить приложение (`npm run dev`) и обработчик (`npm run video:worker`) в двух терминалах. Для создания материалов нужен `VIDEO_GENERATION_ENABLED=true`; при выключенном флаге доступна только проверка подключения. Не запускать второй обработчик поверх первого.
4. Открыть **ту же сборку с готовой озвучкой**. В «Подключение» выбрать **Cloudflare · Stable Diffusion XL · бесплатная Beta**, нажать **Проверить Cloudflare · без генерации**. Проверяется доступ к каталогу модели; это ещё не проверка генерации, квоты или качества.
5. Поставить предел оценки **0 USD**, отметить разрешение запросов и у одного кадра нажать **Создать этот кадр**, подтвердить. Должен появиться один кадр с источником Cloudflare; озвучка сохранится. Обновить страницу и убедиться, что оба результата остались.
6. Если качество устраивает, создать оставшиеся изображения и собрать MP4. Если нет — сначала исправить описание одного кадра и отдельно подтвердить его замену. Ошибка сервиса показывается явно, платный аналог автоматически не вызывается.

Выбор модуля сохраняется для сборки и влияет на будущие запросы. Готовые картинки сохраняют исходный источник, ожидающие задачи проверяются у первоначального сервиса. Новая сборка начинается без выбранного модуля; старые сборки сохраняют совместимость с BFL до явного переключения.

### Кадры без Google API-ключа

Для первого сравнения используйте **Cloudflare · FLUX.2 klein 9B**: он подключается автоматически через уже настроенные CLOUDFLARE_ACCOUNT_ID и CLOUDFLARE_API_TOKEN. Это Workers AI, отдельный баланс BFL не нужен. [Модель](https://developers.cloudflare.com/workers-ai/models/flux-2-klein-9b/) и [тариф Cloudflare](https://developers.cloudflare.com/workers-ai/platform/pricing/) проверены 25 октября 2026: общая бесплатная квота — 10 000 нейронов в день, кадр до 1 Мп — около 1364 нейронов. На Free превышение останавливает запросы; на Paid оплачивается, ориентир $0.015 за кадр 1280×720. Остаток квоты приложение не видит; оценка расхода отображается и при наличии бесплатной квоты.

1. Перезапустите приложение и worker; откройте **ту же сборку → Кадры**. Выберите **Cloudflare · FLUX.2 klein 9B**; выбор сохраняется сразу. В «Настройках сервисов» проверьте подключение. Новые ключи и миграции не нужны, если прежний Cloudflare работал. Проверка каталога не доказывает доступ к генерации.
2. Выберите подходящий общий стиль, например фотографический или кинематографический. Проверьте «Запрос со стилем»: одно видимое действие, место, свет и ракурс. Выберите один кадр и подтвердите отдельный запрос; предел оценки должен быть не меньше $0.015. Сравните с прежним SDXL прежде, чем создавать остальные. Реальная работа нового адаптера и качество ещё требуют этой проверки; одинаковые персонажи пока не гарантируются, референсы адаптер не передаёт.
3. Для сравнения с **Nano Banana** откройте сайт [Flow](https://labs.google/fx/tools/flow), выберите «Изображение», доступную Nano Banana, 16:9 и один результат. Кнопка **«Скопировать промпт для Flow»** в карточке копирует описание с выбранным стилем. Проверьте расход на сайте; доступ к веб-версии не требует Gemini API-ключа. Используйте удачный кадр как референс следующих на сайте. [Официальная инструкция](https://support.google.com/flow/answer/16729550?hl=en).
4. Скачайте изображения PNG/JPEG/WebP. В ScenePilot раскройте **«Кадры из Flow или другого сервиса»**, выберите несколько файлов, назначьте кадры по предпросмотру и подтвердите замену существующих изображений. До 120 файлов, каждый до 16 МиБ, размеры 64–4096 px по каждой стороне. Это локальный импорт без генерации; нужны FFmpeg/ffprobe, запущенный worker для импорта не требуется. Голос и клипы сохраняются; выбранный клип можно сменить на картинку на этапе «Анимация». После изменения материалов пересоберите MP4.

**Один кадр без скачивания файла:** в Flow откройте готовое изображение и выберите «Копировать изображение» (не адрес). В ScenePilot раскройте **«Вставить изображение из Flow»** в нужной карточке, нажмите на область **«Ctrl+V или перетаскивание»**, вставьте Ctrl+V и проверьте миниатюру. Только кнопка **«Добавить в кадр N» / «Заменить изображение кадра N»** отправляет файл на сохранение. Можно также перетащить скачанный файл или выбрать его в этой карточке — назначение уже известно. Если браузер передал лишь ссылку, используйте файл. Лимиты и проверка форматов прежние; API-ключ и worker для вставки не нужны. После обновления достаточно перезапустить приложение.

Произвольные имена Flow в массовом импорте не сопоставляются по порядку. При ошибке нажмите «Проверить состояние перед повтором», проверьте уже сохранённые кадры и выберите только недостающие файлы. Вставка в карточку также останавливается после ошибки без автоматического повтора. Генерация внутри Flow остаётся ручной; API подписки не подключён. Квоты и модели Flow проверяйте в своём аккаунте, бесплатность и доступность не гарантируются.

### Общие детали кадров

В существующей сборке откройте **Кадры → Общие детали кадров**. В одном поле до 800 символов опишите повторяющиеся признаки, например: «Анна: короткие тёмные волосы, зелёное пальто. Берлин, пасмурное утро, естественный свет». В описании конкретного кадра указывайте присутствующих героев и действие. Сохраните описания и общие детали; поле необязательное, пустое значение отключает добавление. Изображения, голос и клипы не меняются, генерация не запускается.

**Итоговый промпт** под каждым кадром показывает описание, стиль и общие детали. **Скопировать промпт для Flow** включает тот же текст и дополнительные инструкции изображения для сайта; несохранённые правки обозначаются как черновик. Генерация по API использует только сохранённые значения. Общий предел описания вместе со стилем и деталями — 2000 символов: при превышении приложение укажет номера кадров без сокращения текста или частичного сохранения. Для новых настроек перезапустите приложение и, при работе через API, worker.

Текст не заменяет референс лица. В Flow к следующему изображению можно приложить удачный предыдущий кадр через **More → Add to Prompt**; [официальная инструкция](https://support.google.com/flow/answer/16729550?hl=en). Передача референсов в API этим шагом не реализована. Первую проверку сохранения и копирования можно выполнить вообще без генерации.

### BFL: первое изображение

Необязательная платная альтернатива Cloudflare. Использовать только при доступном API и способе оплаты; для текущего бесплатного теста подключение BFL не требуется.

1. Открыть [кабинет Black Forest Labs](https://dashboard.bfl.ai), создать аккаунт и API-ключ. Это отдельный сервис изображений; ключ ElevenLabs здесь не подходит. [Официальная инструкция BFL](https://help.bfl.ai/articles/7424166364-wip-welcome-to-the-forest).
2. В существующем `.env.local` добавить или заполнить `BFL_API_KEY=ваш_ключ`. Остальные настройки сохранить; ключ не отправлять в чат. Перезапустить приложение (`npm run dev`) и обработчик (`npm run video:worker`) в двух терминалах из папки проекта.
3. Открыть **ту же сборку**, где уже есть озвучка. В «Подключение» выбрать модуль BFL и нажать **Проверить BFL · без генерации**. Ожидаются баланс кредитов и время проверки либо сообщение об ошибке. Выполняется только GET баланса, без сценария и создания картинок; обработчик и включённая генерация для проверки не нужны.
4. Для генерации требуется баланс BFL. Текущую стоимость, минимальное пополнение и комиссии проверить в кабинете перед оплатой: [тарифы провайдера](https://help.bfl.ai/articles/7986977817-what-are-the-costs-associated-with-using-your-models). Оценка приложения не является текущим биллингом провайдера.
5. У первого кадра раскрыть «Описание изображения», при необходимости поправить и сохранить. В разделе «Генерация материалов» над кадрами задать предел оценки **0.04 USD**, отметить разрешение платного запроса, затем у выбранного кадра нажать **Создать этот кадр** и подтвердить. Должна появиться одна картинка, остальные места остаются пустыми, озвучка сохраняется. После обновления страницы результат должен остаться. Оценить соответствие тексту и внешний вид.
6. Если картинка подходит, установить предел не ниже оценки оставшихся изображений, снова отметить разрешение и нажать **Создать оставшиеся изображения**. После сохранения всех кадров — **Собрать MP4 на компьютере**, просмотреть и скачать видео. Монтаж не обращается к генераторам. Для замены неудачной картинки — отдельная кнопка **Новое изображение**, это новый платный запрос.

Если BFL ещё обрабатывает кадр, доступна проверка существующей задачи без нового POST; замена ожидающего кадра заблокирована. При известном окончательном отказе задача получает ошибку и допускает отдельную подтверждённую замену. Неизвестный статус или временный сбой сохраняет адрес проверки. Успешный запрос баланса сам по себе не подтверждает качество/доступность генерации; фактические списания проверяются в BFL.

### ElevenLabs: первое подключение

Пользователь уже создал и прослушал озвучку ElevenLabs. Для повторной настройки не нужно автоматически покупать новый тариф. Перед дальнейшим выпуском видео проверить в своём аккаунте доступ API, квоту, выбранный голос и условия использования результатов. Старые цены и истёкшая акция удалены из текущей инструкции; история сохранена в архиве.

1. В своём аккаунте открыть [API Keys](https://elevenlabs.io/app/settings/api-keys), создать отдельный ключ `ScenePilot`. Разрешения: **Text to Speech — Access**, **User — Read**, **Voices — Read**. Остальные возможности не требуются. Первые тесты удобно ограничить квотой ключа 5000 кредитов; это рекомендация, не настройка, которую агент уже применил. Проверка подключения не расходует озвучку, но требует двух разрешений Read. Она не подтверждает права на будущую генерацию.
2. В My Voices выбрать голос, прослушать готовый образец и скопировать **Copy voice ID** из меню голоса. Для русского текста выбирать голос, подходящий русскому языку. Voice ID — открытый идентификатор, не API-ключ. Значение по умолчанию в примере — George; его пригодность конкретному ролику не проверена. Голос фиксируется при создании сборки; для его смены нужна новая сборка.
3. Открыть существующий `.env.local` в корне проекта и добавить либо изменить строки ниже. Не заменять весь файл: Supabase и Yandex сохраняются. Не создавать дубли переменных. Вместо пояснений подставить свои значения, секрет не присылать в чат:

```dotenv
ELEVENLABS_API_KEY=ваш_секретный_ключ
ELEVENLABS_VOICE_ID=скопированный_voice_id
VIDEO_GENERATION_ENABLED=false
```

4. Перезапустить `npm run dev`. В проекте с сохранённым коротким сценарием открыть **Видео → Подключение → Проверить ElevenLabs · без генерации**. Ожидаются голос, тариф и остаток квоты. Проверяется голос текущей сборки; если сборки ещё нет — ID из поля. Проверка использует GET к подписке и голосу, не отправляет сценарий и не воспроизводит образцы. Отображаемый остаток не учитывает отдельный лимит ключа и не является гарантией расходов.
5. После выбора платного плана и решения выполнить первый запрос изменить флаг на `VIDEO_GENERATION_ENABLED=true`. Остановить старые процессы и запустить из папки проекта в двух терминалах `npm run dev` и `npm run video:worker`. Перезапуск обработчика может продолжить ранее подтверждённые задачи в очереди.
6. Сохранить сценарий на 30–60 секунд (например, 500–900 символов), создать сборку. На шаге «Озвучка и сборка» раскрыть «Генерация материалов», указать предел **оценки** в USD, отметить разрешение расходов и нажать **Создать только озвучку**. Дополнительное окно показывает конкретное действие. Запрос использует `eleven_multilingual_v2`, MP3 44.1 kHz / 128 kbps и тайминги для субтитров. Для этого BFL не нужен. После появления плеера прослушать дикцию, паузы и ударения; MP3 можно скачать. Удачное аудио используется при следующих шагах без повторной оплаты генерации.

Ориентир в долларах использует публичную API-ставку, а не вычисляет счёт конкретной подписки. Запрос может расходовать включённые кредиты; стоимость подписки, налоги, дополнительные условия голоса и лимит ключа проверяются в кабинете. Автоматических платных повторов нет.

Если проверка сообщает HTTP 401 — проверить ключ, срок и разрешение, указанное в ошибке; HTTP 403 — доступ из страны/сети и разрешения; HTTP 404 — выбранный Voice ID/My Voices. При выключенной генерации проверка работает, а платные кнопки выключены. Если обработчик не виден, проверить второй терминал и перезапуск после изменения `.env.local`. Не включать другие платные сервисы для устранения ошибки ElevenLabs.

Если сайт открывается через Happ, а проверка приложения не работает, проверить режим подключения. **Системный прокси Windows не подхватывается автоматически встроенным fetch в используемом Node.js 20**; браузер и приложение могут ходить разными маршрутами. Для общего сетевого подключения можно выбрать в Happ режим TUN вместо системного прокси, затем перезапустить `npm run dev` и повторить только проверку подключения. Обработчик для этой проверки не нужен. Это не гарантия доступа сервиса: ограничения страны, ключа и аккаунта остаются отдельными проверками. Не отключать проверку TLS и не вставлять HTTP_PROXY в надежде, что Node.js 20 автоматически начнёт его использовать. Настройки сети агент сам не менял. Источники: [сетевая конфигурация Node.js](https://nodejs.org/learn/http/enterprise-network-configuration), [режимы Happ](https://github.com/HappDev/happ_su/blob/main/dev-docs/app-management.md).

Сообщения проверки различают этап (подписка/голос), HTTP-статус, DNS, тайм-аут, отказ соединения, ошибку сертификата, неверный формат заголовка ключа и ответ не в JSON. Строка с Voice ID и разрешениями под кнопкой — инструкция, не сообщение об ошибке. Содержимое ключа, сырые ошибки сети и ответы провайдера не показываются. Успешная проверка ещё не создаёт озвучку: для неё есть отдельная кнопка.

HTTP 400 на этапе голоса не означает недоступность сервиса. Приложение читает известный код из `detail.code` (или прежнего `detail.status`): например, `voice_not_found` означает, что голос не найден при обращении из аккаунта. Добавить нужный голос в My Voices, скопировать оттуда Voice ID и создать **новую сборку**; изменение поля или `.env.local` не меняет голос уже сохранённой сборки. Для проверки 18 октября метаданные контрольного ID `JBFqnCBsd6RMkjVDRZzb` были доступны с ключом пользователя (HTTP 200); синтез этим не проверен. При необходимости начать с него, затем подобрать подходящий голос. Ошибки прав и требований тарифа показываются отдельно, если API возвращает распознанный код; сырой ответ не выводится. [Коды ошибок ElevenLabs](https://elevenlabs.io/docs/eleven-api/resources/errors).

Источники: [тарифы](https://elevenlabs.io/pricing), [API-тарифы](https://elevenlabs.io/pricing/api), [API-ключи и квоты](https://elevenlabs.io/docs/overview/administration/workspaces/api-keys), [Voice ID](https://elevenlabs.io/docs/help-center/technical/how-do-i-find-the-voice-id-of-my-voices-via-the-website-and-api), [ограничения стран](https://elevenlabs.io/docs/help-center/legal/do-you-restrict-access-to-the-service-and-platform-for-any-specific-countries).

Это секреты: не пересылайте эту папку, не добавляйте её в репозиторий или публичное хранилище. Файлы сейчас не зашифрованы дополнительным хранилищем Windows. «Отключить от ScenePilot» удаляет локальные токены; для полного отзыва разрешения используйте настройки аккаунта Runway.

## Сеть и режим разработки

Для загрузки проектов и проверки входа нужен стабильный доступ самого Node.js-приложения к Supabase. Работа сайта в браузере не доказывает маршрут приложения; режим «системный прокси» может отличаться от TUN. Настройки VPN не меняются автоматически.

В next.config.ts отключён serverComponentsHmrCache: при обновлении серверных компонентов в `npm run dev` ответы Supabase не должны попадать в этот дополнительный кэш. После изменения конфигурации остановить dev-сервер через Ctrl+C и запустить снова. Производственный запуск — `npm run build`, затем `npm start`; не запускать одновременно с dev на том же порту. Если задержки сохраняются, см. [диагностику](testing.md#если-соединение-нестабильно).


### Если клип замирает раньше окончания речи

В «Видео → Кадры и движение» показаны длительность речи и поведение клипа. После обновления приложения перезапустите также `npm run video:worker`. Для ранее загруженных файлов нажмите «Автоподгонка всех клипов под озвучку», затем на шаге «Озвучка и сборка» соберите MP4. Новая генерация и оплата не нужны. Новые клипы получают auto сразу; заменяемые сохраняют прежний выбор. В настройках отдельного клипа можно оставить остановку или обычный повтор. Исходный клип в карточке всегда остаётся коротким — подгонка видна в итоговом MP4.


## Nano Banana API и подробный план кадров (21 октября 2026)

Nano Banana — отдельный выбираемый модуль, не автоматическая замена Cloudflare. Подготовлена модель `gemini-nano-banana-2.1`: один кадр 16:9 / 1K через официальный Interactions API. Реальная генерация этим модулем ещё не проверена.

1. Открыть [страницу ключей AI Studio](https://aistudio.google.com/api-keys) в аккаунте, которому принадлежит проект. Нажать **Create API key**, назвать ключ `ScenePilot`, выбрать свой проект. Если его нет — **Dashboard → Projects → Import projects** либо создать собственный проект. Скопировать строку ключа, не ID проекта. Для изображений нужен отдельный платный Gemini API: Google Pro и кредиты Flow его не оплачивают. [Официальные шаги](https://ai.google.dev/gemini-api/docs/api-key).
2. Добавить `GEMINI_API_KEY=ваш_ключ` в существующий `.env.local`, сохранив остальные строки. Перезапустить `npm run dev` и `npm run video:worker`.
3. «Видео → Настройки сервисов → Изображения»: выбрать **Google · Nano Banana 2.1**, нажать проверку без генерации. Она читает сведения о модели, не подтверждает баланс или возможность платной генерации.
4. Для первого реального теста отдельно разрешить расходы и заменить только один кадр. До этого никаких запросов генерации не требуется. Готовые картинки и голос при выборе сервиса сохраняются.

По [тарифу Google](https://ai.google.dev/gemini-api/docs/pricing) на дату проверки: изображение 1K — $0.0336 плюс входные и мыслительные/текстовые токены; бесплатного API-тарифа модели нет. ScenePilot резервирует оценку $0.08 на запрос, а не гарантирует верхнюю границу счёта; контролировать фактические списания нужно в Google. Сетевой тайм-аут не доказывает отсутствие списания, автоматических повторов нет.

Для более частой смены кадров: после готовой озвучки открыть «Кадры и движение → Разделить длинные кадры · необязательно». Выбрать 6/8/10/15 секунд, рассчитать количество, затем создать отдельную сборку. Голос копируется без TTS-запроса; исходная сборка остаётся. Первый фрагмент каждой прежней сцены сохраняет её изображение/клип, остальные требуют новых изображений. Описания механические — проверить до генерации. Длинное слово или пауза могут превысить ориентир. Максимум 120 кадров; лимит 5000 символов и 900 секунд остаётся.

Через подписку: [Flow поддерживает Nano Banana для изображений](https://support.google.com/flow/answer/16729550?hl=en). Это сайт с собственной квотой, не Gemini API; доступную модель и расход проверяйте в аккаунте. В ScenePilot добавлен [массовый импорт готовых изображений](#кадры-без-google-api-ключа). Публичный API кредитов подписки в проверенной документации не найден. Следующий возможный этап — отдельная проверка управления браузером: вход, загрузка, ожидание и скачивание, без скрытых запросов и извлечения cookie. CAPTCHA/повторный вход могут требовать участия пользователя; устойчивость массовой автоматизации ещё не подтверждена.


## Если AI Studio пишет permission denied

`Failed to list bundled Applications` означает отказ при чтении списка приложений; это не диагноз «бан IP/компьютера». Отдельно проверить прямую страницу API Keys: ошибка Build-приложений ещё не доказывает отказ всего API. Для исключения смешанных сессий попробовать отдельное приватное окно с одним аккаунтом. Это диагностический шаг, не гарантированное исправление.

Google требует поддерживаемый регион, возраст 18+ и в некоторых случаях подтверждение возраста; выбранная страна профиля сама по себе этого не доказывает. [Условия доступа](https://ai.google.dev/gemini-api/docs/available-regions). Для ключа в чужом/управляемом Cloud-проекте также нужны права его администратора.

Если AI Studio не работает, официальный альтернативный путь — [Cloud Console → Credentials](https://console.cloud.google.com/apis/credentials): выбрать свой проект, **Create credentials → API key**, ограничить ключ **Generative Language API**, привязать сервисный аккаунт по инструкции Google. Для Gemini нужен соответствующий auth key; не использовать случайный неограниченный ключ. Этот путь не снимает региональные и аккаунтные ограничения. [Инструкция Cloud](https://docs.cloud.google.com/docs/authentication/api-keys). Не менять права организации наугад и не присылать ключ в чат. При повторном отказе нужен точный текст ошибки конкретного шага, без секретов.

## Сценарии и сцены: внешний Claude и API

Сейчас напрямую подключён Yandex. Для текста до 2 минут предел ответа 2000 токенов, для 2–5 минут — 4000, свыше 5 минут — 6000 (YandexGPT 5.1). Объём проверяется по выбранному темпу; короткий ответ остаётся доступен для редактирования с предупреждением. «Доработать объём» — отдельный платный запрос с текущим черновиком, только после подтверждения. Точный хронометраж определяется озвучкой. Генератор сцен до 5 минут обязан сохранить весь текст дословно, кроме пробелов/переносов; при сокращении прежний набор остаётся. Число слов отдельной сцены не обязано быть одинаковым.

Готовые сцены из Claude можно вставить целиком в «Сцены → Вставить сцены из Claude или другой модели»: текст с заголовками СЦЕНА и полями Описание / Визуальный промпт / Озвучка, либо JSON. Импорт — внешний ручной материал, без API-запроса. После проверки нажать «Сохранить сцены». При сетевой неопределённости приложение проверяет результат чтением, не повторяет запись. Кнопки «Проверить сохранение» и «Скачать черновик сцен» доступны отдельно. Черновик не автосохраняется; перед перезагрузкой скачать JSON. Для повторного импорта вставить содержимое JSON в то же поле.

Чтобы озвучка и промпты этих сцен попали в MP4: «Видео → Сценарий → Основа новой сборки → Сохранённые сцены», затем создать новую сборку. Используется именно озвучка сцен, даже если она отличается от сценария; хранится её отдельный снимок. Не включать новую генерацию голоса, если нужен только просмотр плана. Прежняя сборка не меняется. Кадры редактора внутри эпизодов ещё не импортируются.

Для будущего подключения Claude API: открыть [Claude Console](https://platform.claude.com/), создать ключ **Settings → API keys**, проверить баланс **Settings → Billing**. Доступ API использует отдельные кредиты; не покупать Pro только ради ключа. По текущим условиям у Max/Team возможны включённые API-кредиты после привязки Console — смотреть свой кабинет. [Ключи](https://platform.claude.com/docs/en/get-api-key), [биллинг](https://support.claude.com/en/articles/8977456-how-do-i-pay-for-my-claude-api-usage). Адаптер Claude в ScenePilot ещё не реализован; добавление ключа само по себе его не подключит. До этого доступен ручной импорт без отдельной оплаты API. Для экономного сравнения сценариев кандидат — Sonnet; качество нужно оценивать на одной и той же теме, а не по цене модели.


## ElevenLabs: HTTP 402 и план кадров (22 октября 2026)

HTTP 402 означает отказ по условиям оплаты/доступа, а не доказанную неисправность VPN. Остаток квоты в проверке подписки не подтверждает доступ выбранного голоса к TTS. По [документации ElevenLabs](https://elevenlabs.io/docs/eleven-creative/voices/voice-library), голоса Voice Library недоступны через API пользователям Free. Добавление в My Voices этого не меняет. Для бесплатного теста нужен голос с доступом к API на текущем тарифе; работа на сайте этого не доказывает. Если выбранный голос требует платного плана, можно сменить голос или отдельно решить вопрос подписки. Не покупать тариф только на основании общего HTTP 402.

После обновления перезапустить и `npm run dev`, и `npm run video:worker`. В «Видео → Сценарий» выбрать «Сохранённые сцены», вставить выбранный Voice ID и создать новую сборку: 12 сохранённых сцен дадут 12 кадров. Старые сборки не меняются; новая сборка не переносит готовые изображения или аудио. Создание плана бесплатно и не запускает модели. Для сохранения готовых материалов продолжать прежнюю сборку.

В «Настройки сервисов» нажать «Проверить ElevenLabs · без генерации». Сверить голос, тариф, остаток и длину текста; в кабинете проверить разрешение Text to Speech и отдельный лимит API-ключа. Генерацию запускать только после выбора доступного голоса и подтверждения расходов. При повторном отказе сообщить текст из «Нужно внимание» целиком, без ключей. Новая обработка распознаёт известные коды `payment_required`, `quota_exceeded`, `insufficient_credits` и ошибки разрешений; неизвестный ответ не выдаётся за установленную причину. Старое сохранённое сообщение само не обновляется, повтор генерации только ради диагностики не требуется.

Дополнительное деление кадров по готовой речи необязательно и сохраняет озвучку в отдельной сборке. Оно не придумывает разные планы и не обеспечивает одинаковое лицо. Для связной истории нужны осмысленные ракурсы и, в дальнейшем, поддержка визуальных референсов.


## Если video:worker сразу завершается

Выполните `npm run video:doctor`. Проверка использует ту же папку материалов и блокировку, но не запускает очередь, не восстанавливает незавершённые задачи и не вызывает API. Исправная проверка сообщает число прочитанных сборок. Затем запустите `npm run video:worker` и оставьте терминал открытым; ожидается «Обработчик видео запущен».

Если проверка не пройдена, сообщение содержит этап и известный код ошибки: `EACCES`/`EPERM` — доступ Windows, `WORKER_LOCK_BUSY` — работающий процесс, `WORKER_LOCK_INVALID` — повреждённая блокировка, ошибка чтения/JSON — файл сборки. При занятой блокировке сначала остановите прежний обработчик через Ctrl+C. Не удаляйте worker.lock вручную, пока процесс работает. Блокировку завершённого процесса проверка снимает безопасно. Неизвестные сообщения ОС не выводятся: пришлите безопасный вывод диагностики без ключей.

После обновления зависимостей на другом компьютере выполните `npm install`: добавлен Sonner для уведомлений. В текущей рабочей папке он уже установлен. Уведомления в экране видео дополняют постоянный статус; повторные опросы не повторяют генерацию. Кнопка повторной загрузки перечитывает страницу, а не повторяет сохранение или запрос к модели.


## Пять этапов создания ролика

После обновления перезапустите `npm run dev`. Миграции и пересоздание готовых сборок не нужны.

1. **Сценарий:** выберите основу и Voice ID, подготовьте бесплатный план. Существующую сборку можно продолжить кнопкой «К озвучке», а другую основу/голос задать в свёрнутом блоке новой сборки.
2. **Озвучка:** проверьте голос, подтвердите расход и создайте аудио. Прослушайте, затем нажмите «К кадрам».
3. **Кадры:** выберите сервис/стиль, проверьте промпты. После отдельного подтверждения создайте недостающие изображения; готовые материалы и голос сохраняются. «К анимации» ведёт дальше. Можно вместо изображений перейти к добавлению готовых MP4.
4. **Анимация:** по желанию используйте Flow, загрузите клипы и выберите подгонку. «Продолжить без клипов» использует изображения с локальным движением. Для перехода к сборке должны быть голос и материал в каждом кадре.
5. **Сборка:** выберите наличие субтитров, соберите локальный MP4 и скачайте. Здесь нет запуска генерации голоса или изображений.

Верхние этапы позволяют вернуться к настройкам. Смена этапа не запускает модели; на новом этапе разрешение расхода подтверждается отдельно. Статус задачи и «Обновить состояние» видны всегда. В «Сборки этой версии» можно выбрать прежнюю сборку: приложение откроет подходящий этап по её материалам.
