# Производство видео и следующий шаг Flow

Актуально на 21 октября 2026. Этот документ описывает путь ролика; очередь разработки находится только в [roadmap.md](roadmap.md).

## Доступный путь

1. Выбрать профиль и замысел, создать ролик, сохранить версию сценария.
2. В «Видео» подготовить план и проверить описания кадров. План бесплатный, механический: он не доказывает художественное качество.
3. Создать озвучку ElevenLabs по отдельному подтверждению; прослушать результат.
4. Выбрать Cloudflare SDXL, Nano Banana API либо необязательный BFL, проверить доступ, создать и оценить один кадр. Затем остальные. Готовая озвучка сохраняется при смене модуля изображений.
5. Для движения модели вручную подготовить кадр/промпт для Flow, получить клип в своём аккаунте и импортировать MP4. Источник материала обозначается; локальное движение картинки не считается генерацией видео моделью.
6. Выбрать субтитры и поведение короткого клипа (auto/hold/loop), собрать и просмотреть MP4. Монтаж исключает звук импортированного клипа и использует прежнюю озвучку.

Подключение, локальные файлы и секреты — [setup.md](setup.md#локальное-производство-видео). Создание и оплата материалов — отдельное решение пользователя. Текущие условия сервисов проверяются перед запуском в аккаунте; старые тарифные расчёты не являются действующими ценами.

## Реальные границы

- Редактор: до 20 000 символов сценария и цель до 900 секунд. Yandex-сцены для длинной цели пока ограничены; см. [архитектуру](architecture.md#текущие-пределы).
- Производство: до 5000 символов, до 120 кадров как начального плана, так и раскадровки по готовой речи, до 900 секунд аудио; выход 1280×720, 24 fps. План кадров производства отделён от редактора кадров внутри эпизодов.
- Импорт: MP4 до 32 МиБ и одной минуты, проверка ffprobe. Пользователь подтвердил перенос и сборку; заметил стоп-кадр при длинной озвучке. Пользователь предварительно подтвердил автоподгонку.
- Задачи и готовые файлы локальны. Автоматической очистки нет. Удаление проекта из Supabase не удаляет локальные файлы и не отменяет ранее подтверждённую задачу.
- Движение целого изображения и повтор короткого клипа не создают час уникальной анимации. Полный длинный выпуск ещё не проверен.

## Выбранный путь Flow

20 октября пользователь выбрал использовать уже оплаченную подписку Flow: сейчас удобный перенос клипов, затем исследование управления браузером. Новое платное API не подключаем автоматически.

Проверены официальные [условия кредитов Flow](https://support.google.com/flow/answer/16526234?hl=en-GB) и [тарифы Gemini API](https://ai.google.dev/gemini-api/docs/pricing). У Flow есть кредиты подписки, Veo API относится к отдельному платному доступу. Публичный программный интерфейс для расходования кредитов Flow в проверенной документации не найден. Это ограничение исследования, а не доказательство невозможности любой автоматизации.

На шаге «Кадры и движение» раскрыть «Анимировать кадр N в Flow»: скачать изображение, выбрать неподвижную камеру/приближение/панораму, скопировать шаблон, открыть Flow. Выбор камеры временный, до обновления страницы; шаблон редактируется на сайте. Сохранённый MP4 загружается здесь же в этот кадр. Наличие загруженного файла не доказывает его происхождение из Veo. Подключения доступны через «Настройки сервисов»; разрешение запросов изображений/озвучки — через «Генерация материалов».

Следующий шаг после приёмки: исследовать управление доступным пользователю браузером — вход, загрузку кадра, выбор модели/числа результатов, отображение расхода, ожидание и скачивание. Сначала проверить без запуска генерации. Не извлекать cookies/токены и не подменять браузер недокументированными HTTP-вызовами. Действие с расходом кредитов согласовать отдельно; при неопределённом результате не нажимать генерацию повторно.

Минимальная реальная приёмка: один короткий клип по исходному кадру, одна подтверждённая генерация, проверка расхода, импорт и сборка с прежней озвучкой. Если интерфейс требует ручного входа или подтверждения, оставить этот шаг пользователю.


## Длительность и длинные выпуски

Перед работой в Flow создать и прослушать озвучку: у кадров появятся их длительности. Новый импорт использует автоподгонку: обрезка, небольшое замедление или повтор со сглаженным стыком. Для прежних клипов есть «Автоподгонка всех клипов под озвучку»; затем требуется локальная пересборка MP4. Это не расходует кредиты модели. Повтор заметнее на однократных действиях; спокойные цикличные движения подходят лучше. Все исходники и звук сохраняются.

По скриншотам пользователя в Flow выбрана Omni 1.1 Flash, 720p, 16:9, 10 секунд, x1; такая конфигурация подходит текущему 720p-монтажу. Название модели не доказывает качество. Google описывает [Extend только для клипов Veo](https://support.google.com/flow/answer/16935718); это отдельная генерация, а не бесплатный локальный монтаж. Проверять условия и расход на сайте перед каждым запуском.

Подробный план по реальным таймингам речи реализован и ожидает пользовательской приёмки; далее — главы с отдельной озвучкой, восстановлением и итоговой сборкой. Нельзя получить час уникальных событий простым повтором 10-секундного клипа или гарантировать 10 секунд речи одним указанием в промпте. Текущие ограничения: 5000 символов озвучки, 120 кадров, 900 секунд аудио.


Подробная раскадровка создаёт отдельную сборку с готовым голосом и новыми короткими кадрами. Она необязательна для подгонки клипа: её цель — разнообразие визуального ряда. После пользовательской проверки — главы и возобновляемая озвучка частями; часовые ролики пока не обещаются. Nano Banana API подготовлен отдельно; реальный тест и браузерная автоматизация Flow ещё впереди. Инструкция и условия подписки — [setup.md](setup.md#nano-banana-api-и-подробный-план-кадров-21-октября-2026).
