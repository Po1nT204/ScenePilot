# ScenePilot: готовое видео

18 октября 2026. Пользователь подтвердил генерацию Cloudflare и первичную сборку видео после ранее принятой озвучки ElevenLabs. Путь MP4 получил предварительную приёмку, художественное качество — нет. Текущий шаг: субтитры по выбору, стиль изображений и разбиение на предложения. Настоящую анимацию будем подключать после проверки предложения API, ссылку на которое пользователь обещал прислать. Прежние спринты в roadmap.md остаются историей.

## Результат

Личный инструмент: сценарий или тема → озвучка → изображения → анимация → субтитры → готовый MP4. Русский и английский, в перспективе длительность до нескольких часов. Главный критерий — качество ролика; публичный сервис и маркетинг сейчас не нужны.

Первый результат: 30–60 секунд, озвучка, шесть изображений с плавным движением, субтитры, просмотр и скачивание. Отдельный кадр можно заменить и пересобрать без генерации остальных материалов. Движение картинки не выдаём за видео, созданное моделью; такую анимацию подключаем следующим этапом. Короткий тест не ограничивает будущую длительность.

## Что проверено на компьютере

- Windows x64; Intel Pentium 4417U, 4 логических процессора; 7,9 ГиБ RAM, около 1 ГиБ свободно на момент проверки; на C: около 77,6 ГиБ свободно.
- Доступны Node.js 20.19.6, npm 10.8.3, Python 3.14.0, FFmpeg/ffprobe (сборка 18 марта 2026), Git; node_modules существует. Ничего не устанавливалось.
- FFmpeg запускается и содержит libx264/AAC, subtitles, zoompan, scale и concat. Это проверка возможностей сборки, не скорости рендера и не готового MP4. CIM недоступен в среде агента; CPU и память получены через Node os. Модель GPU и работоспособность аппаратного ускорения не подтверждены.
- Вывод: генерацию предложено выполнять через API, сборку — локально, последовательно по фрагментам. Remotion, Docker, новую БД и локальные большие модели для первого результата не добавляем. Скорость и многочасовой рендер ещё требуют измерений.

## Предложенная связка и расходы

Актуализация 18 октября: озвучка ElevenLabs создана и прослушана пользователем. BFL пополнить не удаётся; он больше не является обязательным выбором. Добавлен выбор Cloudflare SDXL для бесплатного теста. Доступ к нему и качество из аккаунта пользователя ещё не подтверждены. Максимальный бюджет нового платного прогона не назван.

| Часть | Предложение | Основание |
| --- | --- | --- |
| Голос | ElevenLabs, Multilingual v2, API с таймингами | Возвращает аудио и временную разметку символов; из неё строим субтитры |
| Изображения | Cloudflare SDXL Beta либо BFL FLUX1.1 pro, выбор пользователем | Отдельные адаптеры, готовые файлы и монтаж не привязаны к одному сервису; качество предстоит оценить |
| Сборка | Уже установленный FFmpeg через Node.js | Субтитры, движение изображений, H.264/AAC MP4; Python для этого пути не требуется |
| Текст | Готовый сценарий для первого прогона; существующий Yandex сохраняется | Позволяет отдельно оценить производство видео; проблему качества текста ещё нужно разобрать на реальном примере |

Прежний пример с BFL: **1000 символов Multilingual v2 × $0,08/1000 + 6 изображений × $0,04 = $0,32** расхода API без налогов, комиссий, текста, видеоанимации и повторов. При выборе Cloudflare SDXL текущая оценка изображений — $0; готовая озвучка повторно не создаётся. Это не расчёт подписки и не гарантия доступности бесплатного API. 1000 символов не обещают точной минуты озвучки; расходы агентом не разрешены и не выполняются.

[Подписка Runway на сайт и API имеют разные балансы](https://help.runwayml.com/hc/en-us/articles/50683115755155-Runway-API-FAQs). До покупки у продавца нужны точные API endpoint, модель, способ получения ключа и отдельный баланс. Наличие подписки/аккаунта в объявлении недостаточно. Цена месячной подписки сама по себе не сравнивает стоимость API одного ролика.

Сообщения пользователя о недоступной стране Gemini и `Failed to list imported projects: permission denied` в AI Studio не доказывают бан оборудования или IP. [Google перечисляет](https://ai.google.dev/gemini-api/docs/troubleshoot-ai-studio) регион, условия аккаунта и права проекта среди причин. Проверить один личный аккаунт в отдельной сессии, возрастные требования и доступ к собственному проекту Cloud Console; покупка подписки не гарантирует устранения ошибки. Google сейчас не является зависимостью первого MP4.

ElevenLabs официально блокирует подключения из России и ряда других стран. Поэтому прямое подключение остаётся условным до проверки доступного пользователю способа работы. Покупка подписки или доступа через посредника сама по себе не подтверждает работоспособность API и таймингов. BFL также не проверялся из аккаунта пользователя. Ключи в чат не нужны. Если подключение недоступно, подбираем замену до покупки; не подменяем провайдера молча.

## Реализованное устройство

Сохраняем Next.js/TypeScript, существующие проекты, версии и Supabase. Шаблон Сухарева используем для организации, без переноса стека. Доступ к чужим проектам остаётся запрещён сервером и RLS.

Добавлен экран «Видео» выбранной версии: слева сценарий и голос, в центре кадры с изображениями, справа просмотр. Видны состояние работы, оценка расходов и действия создания материалов, сборки и скачивания. Промпты и подключение раскрываются по необходимости. Названия/описания и текстовый экспорт остаются вспомогательными. Для первого варианта: 5000 символов сценария, автоматическое разбиение максимум на шесть кадров, 720p/24 fps. Существующие сцены в БД не изменяются и не импортируются автоматически.

Код: раздел projects/[id]/video, компонент video-studio, модули production для файлов, состояния задач и адаптеров; отдельный Node-процесс scripts/video-worker.ts. FFmpeg вызывается без shell, с массивом проверенных аргументов. Производство не удерживает запрос страницы.

Для личного локального запуска состояние задач — версионированные JSON-файлы с атомарной записью и одним исполнителем. По умолчанию файлы находятся в %LOCALAPPDATA%/ScenePilot/production, вне public, Git и OneDrive. Путь настраивается через SCENEPILOT_MEDIA_DIR. Новых облачных таблиц нет. Пользовательская папка производства агентом не заполнялась: проверки использовали отдельные временные каталоги.

Каждая задача фиксирует владельца, проект, версию, снимок изменяемого плана кадров, настройки, стадии, файлы и ID запросов провайдеров. Просмотр/скачивание проверяют текущую сессию и владельца проекта; пользовательские пути файлов не принимаются. Локальный исполнитель получает только задания, созданные проверенным серверным действием.

Порядок: сохранить план → получить озвучку с таймингами → получить изображения → сформировать субтитры → собрать фрагменты → собрать MP4. План кадров должен покрывать текст без потерь; тайминг берём из аудио, а не из слов в минуту. Готовые файлы переиспользуются. Повреждённый/прерванный результат не считается готовым.

При перезапуске сохраняются завершённые стадии. Неизвестный результат платного запроса получает отдельное состояние; автоматической повторной генерации нет. Для BFL сохраняем ID/URL проверки и скачиваем результат до истечения ссылки. После сбоя рендера можно продолжить локальную сборку без запроса моделей. Изменение голоса/текста помечает зависимые материалы устаревшими; замена картинки сохраняет озвучку.

## Этапы и проверка

1. **Подготовка — выполнена.** Компьютер, схема, кандидаты API и расчёт выше. Подключения и бюджет остаются открытыми.
2. **Первый MP4 — пользователь подтвердил работу.** Озвучка, изображения и первичная сборка работают по его сообщению; полный чеклист синхронизации, восстановления и художественного качества этим не закрыт.
3. **Качество и видеоанимация.** Исправить конкретные недостатки просмотренного ролика, подключить выбранную video-модель с отдельной оценкой расходов.
4. **Длинные видео.** Главы, продолжение после сбоя, расширение ограничений, замеры ресурсов на возрастающей длительности. Сейчас ограничения — 900 секунд, 20 000 символов, 12 эпизодов, 240 кадров на версию; их простое увеличение не доказывает многочасовую работу.
5. **Ежедневный запуск.** Упростить запуск и пресеты; отдельная Windows-упаковка только при необходимости.

Приёмка первого MP4: файл проигрывается целиком, голос не обрывается, кадры соответствуют тексту, субтитры совпадают с речью; замена кадра не вызывает остальные генераторы; перезапуск сохраняет готовые материалы. Технические проверки выполняет агент. Пользователь смотрит и слушает результат. Подставные ответы не подтверждают качество и работу облака.

Выполнены локальные тесты логики, запуск обработчика, технический рендер синтетических материалов и браузерная проверка компонента с подставными действиями. Точные результаты — в testing.md. Реальная генерация, облачные изменения, платежи и установки не выполнялись. Бюджеты прошлых шагов не являются разрешением на новые расходы. Инструкция подключения — в [setup.md](setup.md#локальное-производство-видео).

Технические подробности и документы поддерживает агент; пользователю достаточно короткого результата в чате и приёмки законченного этапа. [Мастер-промпт](master-prompt.md), [текущая архитектура](architecture.md), [проверки приложения](testing.md).
