# ScenePilot

ScenePilot помогает автору подготовить материалы для видео: замысел, сценарий, описание кадров, визуальные промпты и текст озвучки. Один проект соответствует одному ролику. Материалы сохраняют связь с конкретной версией сценария.

## Возможности и статус

- Регистрация, вход и собственные проекты с серверной проверкой владельца и RLS.
- Ручной ввод, бесплатные тестовые шаблоны и серверная генерация YandexGPT.
- Неизменяемые версии сценария со снимками настроек.
- Создание, редактирование и сохранение сцен выбранной версии.
- Экспорт TXT/Markdown, предпросмотр и копирование сохранённых материалов.
- Библиотека «Мои ролики» с прямыми переходами к материалам.
- Общая панель «Настройки / Сценарий / Сцены / Экспорт» с сохранением выбранной версии.

Основной учебный MVP проверен пользователем по частям. Второй спринт улучшает UI/UX и рабочий процесс. Библиотека получила предварительную пользовательскую приёмку; общая панель — текущее изменение, ожидающее ручной проверки. Профиль канала, помощь с идеями и описание для YouTube пока запланированы. Приложение не объявляется готовым к публичному запуску.

## Стек и зависимости

Next.js 16, React 19, TypeScript, Supabase Auth/PostgreSQL, серверный HTTP-адаптер YandexGPT. Точные версии закреплены в package.json и package-lock.json. Требуется Node.js 20.19+ и npm; проверяемая среда — Node.js 20.19.6. Docker и локальная база данных не нужны.

## Локальный запуск

```powershell
npm ci
npm run dev
```

Открыть http://127.0.0.1:3000. Сервер слушает только локальный интерфейс; остановка — Ctrl+C. Без Supabase доступны главная страница и инструкция настройки; для работы с проектами нужен интернет и настроенная облачная база.

Для первой настройки скопировать `.env.example` в `.env.local`, **только если такого файла ещё нет**, и заполнить переменные локально. Существующий файл не перезаписывать. Значения секретов не отправлять в чат и не коммитить.

Полная [инструкция настройки Supabase, пяти миграций и YandexGPT](docs/setup.md). Уже применённые миграции повторять не нужно; изменения интерфейса второго спринта миграций не требуют. Yandex необязателен для ручной работы и бесплатных тестовых шаблонов. После изменения окружения перезапустить сервер.

Для production-проверки локально:

```powershell
npm run build
npm start
```

Перед npm start остановить dev-сервер на том же порту. Это локальный запуск, не публичное развёртывание.

## Проверки

```powershell
npm test
npm run lint
npm run typecheck
npm run build
```

Тесты используют подставные ответы Yandex и не выполняют платную генерацию. Сборка включает TypeScript. [Актуальные результаты, ручные чеклисты и SQL-проверки доступа](docs/testing.md).

## Основные ограничения

Сейчас: русский/английский язык, длительность проекта 1–300 секунд, сценарий до 20 000 символов, 1–12 сцен. Длительность — ориентир. Черновик автоматически не сохраняется; рекомендуется одна вкладка на проект. Сцены внутри версии редактируются без истории правок. Экспорт использует только сохранённые материалы.

Реальная генерация запускается отдельной кнопкой с подтверждением. Фактический расход Yandex неизвестен, встроенной денежной блокировки нет. Бюджет и временные условия октября 2026 описаны в [setup.md](docs/setup.md). Известные ограничения безопасности, инструментов и непроверенные случаи перечислены в [testing.md](docs/testing.md).
