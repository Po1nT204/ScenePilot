# ScenePilot

ScenePilot помогает автору подготовить материалы для видео: замысел, сценарий, описание кадров, визуальные промпты и текст озвучки. Один проект соответствует одному ролику. Материалы сохраняют связь с конкретной версией сценария.

## Возможности и статус

- Регистрация, вход и собственные проекты с серверной проверкой владельца и RLS.
- Ручной ввод, бесплатные тестовые шаблоны и серверная генерация YandexGPT.
- Неизменяемые версии сценария со снимками настроек.
- Ручное добавление, редактирование, удаление и перестановка сцен выбранной версии; отдельный источник каждой сцены.
- Экспорт: чистый текст озвучки, визуальные промпты и полный архив TXT/Markdown; предпросмотр, копирование и скачивание сохранённых материалов.
- Библиотека «Мои ролики» с прямыми переходами к материалам.
- Общая панель «Настройки / Сценарий / Сцены / Публикация / Экспорт» с сохранением выбранной версии.
- Профиль канала: аудитория, темы, тон, формат, язык и нежелательные обороты.
- Помощник нового ролика: три варианта названия и замысла, тестовый режим и отдельный запрос YandexGPT, применение в редактируемую форму.
- Материалы публикации по сохранённой версии: заголовок, до трёх вариантов, описание, ручной ввод, тестовый шаблон и YandexGPT; отдельное копирование и включение в экспорт.
- Подготовка длинного пилота: цель до 15 минут, оценка времени озвучки и сравнение текста сцен со сценарием. Длинный текст пока вводится вручную.

Второй спринт завершён как этап разработки с предварительной пользовательской приёмкой, включая подготовку длинного пилота («вроде пока что работает»). Пользователь ранее подтвердил корректный доступ двух аккаунтов. Это не подтверждение всех миграций, SQL-тестов и полного ручного чеклиста. Настоящий пилот на 8–12 минут не пройден и отложен до улучшений приложения. В третьем спринте реализован шаг чистого экспорта, ожидается приёмка. Приложение не объявляется готовым к публичному запуску.

## Стек и зависимости

Next.js 16, React 19, TypeScript, Supabase Auth/PostgreSQL, серверный HTTP-адаптер YandexGPT. Точные версии закреплены в package.json и package-lock.json. Требуется Node.js 20.19+ и npm; проверяемая среда — Node.js 20.19.6. Docker и локальная база данных не нужны.

## Локальный запуск

```powershell
npm ci
npm run dev
```

Открыть http://127.0.0.1:3000. Сервер слушает только локальный интерфейс; остановка — Ctrl+C. Без Supabase доступны главная страница и инструкция настройки; для работы с проектами нужен интернет и настроенная облачная база.

Для первой настройки скопировать `.env.example` в `.env.local`, **только если такого файла ещё нет**, и заполнить переменные локально. Существующий файл не перезаписывать. Значения секретов не отправлять в чат и не коммитить.

Полная [инструкция настройки Supabase, миграций и YandexGPT](docs/setup.md). Для профиля применить **202610150001_channel_profiles.sql**, затем **202610150002_channel_profile_limits.sql**. Если первая уже выполнена, нужна только вторая: она согласует лимиты базы с формой. Старые файлы не повторять. Yandex необязателен для ручной работы и бесплатных тестовых шаблонов. После изменения окружения перезапустить сервер.

Для управления сценами после них применить **202610150003_scene_editing.sql**: добавляется ручной источник и сохранение смешанного набора. Порядок и удаление меняются только после «Сохранить сцены»; очистка всего набора требует отдельного подтверждения.

Для вкладки «Публикация» и обновлённого экспорта затем применить **202610150004_publication_materials.sql**. Она добавляет отдельное хранилище материалов по версиям. Уже применённые миграции повторять не нужно.

Для цели до 15 минут затем применить **202610150005_long_pilot_duration.sql**. Она расширяет только ограничение длительности проекта, сохраняя старые версии и их снимки.

Для production-проверки локально:

```powershell
npm run build
npm start
```

Перед npm start остановить dev-сервер на том же порту. Это локальный запуск, не публичное развёртывание.

## Проверки

```powershell
npm test
npm run lint
npm run typecheck
npm run build
```

Тесты используют подставные ответы Yandex и не выполняют платную генерацию. Сборка включает TypeScript. [Актуальные результаты, ручные чеклисты и SQL-проверки доступа](docs/testing.md).

## Основные ограничения

Сейчас: русский/английский язык, длительность проекта 1–900 секунд (до 15 минут), сценарий до 20 000 символов, до 12 сцен (генерация возвращает 1–12, редактор позволяет очистить набор). Длительность — ориентир. Черновик автоматически не сохраняется; рекомендуется одна вкладка на проект. Сцены внутри версии редактируются без истории правок. Экспорт использует только сохранённые материалы.

Для цели свыше 5 минут полный сценарий вводится вручную; сцены можно создать вручную или бесплатным механическим разбиением. Yandex-генерация полного сценария и сцен пока ограничена целью до 5 минут. Идеи и тексты публикации доступны с прежними лимитами запросов. Оценка озвучки считает слова при выбранном темпе (условно 140 слов/мин по умолчанию), не измеряет реальную запись и не проверяет факты.

Требования канала копируются в новый ролик и затем в новые версии сценария. Изменение профиля не обновляет старые ролики. Источник замысла хранится отдельно от источника сценария. Идеи не сохраняются автоматически и не являются прогнозом популярности или проверкой фактов.

Материалы публикации относятся к одной версии и редактируются без истории. Заголовок — до 100, описание — до 5000 символов; это лимиты приложения. Копирование берёт текущий текст редактора, экспорт — сохранённый. Отправки на YouTube, автоматической проверки фактов и расчёта таймкодов нет.

Реальная генерация запускается отдельной кнопкой с подтверждением. Фактический расход Yandex неизвестен, встроенной денежной блокировки нет. Бюджет и временные условия октября 2026 описаны в [setup.md](docs/setup.md). Известные ограничения безопасности, инструментов и непроверенные случаи перечислены в [testing.md](docs/testing.md).
