# ScenePilot

Личный инструмент для подготовки и сборки видео: замысел → сценарий → озвучка и кадры → субтитры → MP4. Один проект — один ролик, материалы связаны с версией сценария.

Работают профили каналов, шаблоны хуков и удержания, библиотека с поиском, версии, сцены, публикационные тексты и экспорт. Пользователь подтвердил озвучку ElevenLabs, изображения Cloudflare и первичную сборку MP4; художественное качество ещё требует работы. Автоматизация Veo/Flow — следующий этап, сейчас клипы переносятся вручную.

## Запуск

Нужны Node.js 20.19+ и настроенный Supabase. При первой установке: `npm ci`, затем [настройка](docs/setup.md). Если приложение уже работает, повторять установку и миграции не нужно.

```powershell
npm run dev
```

Открыть http://127.0.0.1:3000. Для обработки видео отдельно запустить:

```powershell
npm run video:worker
```

Обработчику нужны FFmpeg и ffprobe. Имена переменных — в [.env.example](.env.example); секреты хранятся только в локальном `.env.local`, не в чате и не в Git. Существующий файл не перезаписывать.

Если обработчик сразу закрывается: `npm run video:doctor` проверит папку материалов и блокировку без запуска генерации. [Как исправить ошибку запуска](docs/setup.md#если-videoworker-сразу-завершается).

Сейчас редактор поддерживает цель до 15 минут и сценарий до 20 000 символов. Длинный сценарий можно подготовить по частям: у каждой сборки предел 5000 символов озвучки и 900 секунд аудио. Готовые части объединяются в один MP4 на этапе «Сборка», без новой генерации. Полный длинный выпуск ещё требует пользовательской проверки; часовой формат и публичный запуск не готовы.
